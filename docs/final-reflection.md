# Final Reflection

## 1. What We Built

Our team developed RSU Nexus – Campus Resource Marketplace, a web-based platform that allows RSU students to discover, borrow, rent, share, and offer equipment, learning resources, tutoring, and student services through one centralized marketplace. The prototype includes resource browsing, search and filtering, listing details, request submission, messaging between users, request tracking, and an administrative dashboard.

---

## 2. What We Learned About Users

Through user testing, we learned that students prefer having all campus resources available in one place instead of searching through multiple class chat groups and social media platforms. Testers found the browsing and request process easy to understand, but suggested improving interface labels, navigation clarity, and status visibility. Users also appreciated the messaging feature for communicating directly with resource owners.

---

## 3. What We Learned About Requirements

We learned the importance of maintaining requirement traceability throughout the project. Every implemented feature was connected to the system requirements, user stories, and prototype screens. Keeping documentation aligned with development made it easier to demonstrate project progress and prepare for the final presentation.

---

## 4. What We Improved After Testing

Based on user feedback, we improved:

- Clearer navigation and marketplace labels.
- Better request form validation.
- Improved request status tracking.
- More consistent user interface design.
- Better organization of marketplace categories.
- Documentation consistency across all project files.

These improvements increased the usability and overall quality of the prototype.

---

## 5. What Was Difficult Technically

The biggest technical challenges included integrating Supabase with the frontend, designing a consistent database structure, implementing user authentication and request management, maintaining documentation traceability, and coordinating contributions across multiple team members in one GitHub repository.

---

## 6. What We Would Improve Next

If more development time were available, we would:

- Add real-time notifications.
- Improve the messaging system.
- Add ratings and reviews for users.
- Implement advanced search and recommendation features.
- Optimize the interface for mobile devices.
- Strengthen security and administrative management features.
