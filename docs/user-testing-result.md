## 4. User Feedback Summary

### Users Liked
- Modern and professional interface.
- Easy navigation between marketplace pages.
- Fast search experience.
- Clean listing detail pages.
- Helpful marketplace concept for the RSU community.

### Users Disliked
- Some status labels were difficult to notice.
- Form validation messages could be clearer.
- Dashboard information could be explained better.

### User Suggestions
- Add more resource categories.
- Improve search filters.
- Add notifications for request status updates.
- Add favorites/bookmarks for frequently viewed listings.

---

## 5. Evidence-Based Decision

### ✅ Decision:
Needs Minor Revision Before Lab 14

### Explanation

User testing shows that the main workflow is functional and easy to understand. Most testers successfully searched resources, viewed listings, and submitted requests. The remaining issues mainly involve interface clarity, form validation messages, dashboard readability, and additional search filters. These improvements are relatively small and can be completed before the final MVP release in Lab 14.
