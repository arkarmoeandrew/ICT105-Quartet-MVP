# Landing Page Content

## Project Title
RSU Nexus – Campus Resource Marketplace

## Target User
RSU students who need to borrow, rent, share, or offer equipment, learning resources, tutoring, and student services within the university community.

## Headline
Discover, Borrow, Rent, and Share Campus Resources in One Place.

## Subheadline
RSU Nexus connects students with equipment, textbooks, tutoring, and campus services through one trusted marketplace. Quickly find what you need or offer resources to others in the RSU community.

## Problem Statement
Students often spend too much time searching through class chats and social media to find equipment, textbooks, tutors, or campus services. Information is scattered, requests are difficult to track, and many useful resources remain unused because there is no central platform.

## Solution Description
RSU Nexus provides one marketplace where students can browse listings, search by category, create resource listings, submit requests, communicate with providers, and track request status through a simple and organized interface.

## Key Features

| Feature | Requirement ID | User Value | Prototype Screen/Module |
|---------|----------------|------------|-------------------------|
| Homepage and marketplace browsing | FR-01 | Quickly discover available campus resources | Homepage |
| Create listing | FR-03 | Easily offer equipment, tutoring, or services | Create Listing Form |
| Search and filter | FR-06 | Find resources faster by category or keyword | Marketplace |
| Resource detail and request | FR-07 | View complete information before making a request | Detail View |
| Dashboard and request tracking | FR-12 | Track listings and requests in one place | Dashboard |

## Benefits
- Saves time searching for campus resources.
- Makes borrowing, renting, sharing, and offering resources easier.
- Connects students through one trusted campus marketplace.
- Improves resource availability and reuse within the RSU community.
- Provides a clear workflow for requests and communication.

## Call-to-Action
**Explore RSU Nexus and discover campus resources today.**

Primary CTA Button:
**Explore Marketplace**

Secondary CTA Button:
**Create a Listing**

## Responsible Data Message
RSU Nexus only collects the information necessary to provide marketplace services, such as listing details and contact information. Personal data is handled responsibly, used only for prototype functionality, and is not shared with third parties without user consent.
