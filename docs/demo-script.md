# Demo Script

## Demo Objective

Demonstrate how RSU Nexus helps RSU students quickly discover, borrow, rent, share, offer equipment, learning resources, tutoring, and student services through one centralized campus marketplace. The demo will prove that users can complete the main workflow from exploring the marketplace to communicating with resource owners, submitting requests, and tracking request status.

## Demo Flow

| Step | Screen / Feature | What Presenter Says | Requirement ID | Expected User Value |
|------|------------------|---------------------|----------------|--------------------|
| **1** | Landing Page / Homepage | Introduce RSU Nexus, explain the campus resource problem, and describe who the platform is for. | **FR-01** | Users immediately understand the platform's purpose and value. |
| **2** | Explore Marketplace | Click the **Explore Marketplace** button and explain how users browse available equipment, textbooks, tutoring, and student services. | **FR-02** | Users can quickly begin exploring available campus resources. |
| **3** | Search & Filter | Demonstrate searching for a DSLR camera and filtering listings by category and availability. | **FR-05, FR-06** | Users can easily find relevant resources without browsing everything manually. |
| **4** | Listing Detail | Open a listing and explain its description, availability, owner information, rental/borrowing details, and request options. | **FR-07** | Users understand everything before making a request. |
| **5** | Message Owner | Demonstrate sending a message to the resource owner to ask about availability or rental details before requesting. | **FR-07, FR-08** | Users can communicate directly with resource owners before making decisions. |
| **6** | Submit Request | Show how a borrowing, rental, or service request is submitted using the request form and validated successfully. | **FR-03, FR-10, FR-11** | Users can submit valid requests and receive confirmation. |
| **7** | Request Status & Dashboard | Display request status, user dashboard, marketplace statistics, and explain how administrators manage listings and requests. | **FR-08, FR-09, FR-12** | Users can monitor request progress while administrators manage the marketplace efficiently. |
| **8** | Closing | Summarize how RSU Nexus connects students with campus resources through one trusted marketplace and invite everyone to try the prototype. | **FR-16** | Users understand the overall value of the platform and are encouraged to use it. |

## Closing Statement

**RSU Nexus simplifies the way RSU students discover, borrow, rent, share, offer equipment, learning resources, tutoring, and student services. Instead of searching through multiple chat groups and social media platforms, students can use one trusted marketplace to explore resources, communicate directly with resource owners, submit requests, and track their progress. We invite everyone to explore the prototype and share feedback to help us improve the platform before the final MVP release.**
